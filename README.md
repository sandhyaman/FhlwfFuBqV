# Python豆瓣图书数据可视化分析系统（源码）简介

## 核心功能
- 图书数据爬取
- 书籍分析
- 种类分析
- 信息分析
- 评论分析
- 年份分析
- 标题词云
- 简介词云
- 图书推荐

## 适用场景
- 教育研究
- 数据分析
- 图书馆管理
- 读者推荐系统

## 技术特点
- 使用Django框架构建
- 数据存储于MySQL数据库
- 前端界面采用HTML、CSS和JavaScript技术
- 支持数据可视化展示
